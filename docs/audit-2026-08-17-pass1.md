## Framing

1. **Sandbox app** — synthetic wallets/markets/transactions (`README.md`). Only live feeds are
   DefiLlama token USD prices (`convex/prices.ts`) and FX rates (`app/api/fx-rates/route.ts`).
   Task 3 is about internal consistency / single source of truth, not wiring Chainlink.
2. **A large perf pass already landed** (`docs/performance-audit-2026-07-15.md`, 33+ commits):
   wallet SDK off guest critical path, request-scoped `React.cache`, consolidated price
   subscriptions. So "feels slow after first paint" is a re-render/interaction problem.

## TASK 1 — Performance

**Root cause: a re-render cascade that defeats the app's own split-context design.**

- Provider splits state into 8 isolated contexts to contain re-renders
  (`avana-sessions-provider.tsx:287–324`).
- Every session hook returns a bare object literal with **no `useMemo`**
  (`use-lend-session.ts:399`, `use-borrow-session.ts:476`, multiply/swap/rewards/umbrella
  equivalents). All 8 hooks run inside the one provider component.
- The lend accrual `setInterval(…, 30_000)` (`use-lend-session.ts:233`) re-renders the provider
  every 30s → new identities for all 8 context values → **every consumer of every product
  re-renders every 30s**, plus on any borrow/swap/reward action.
- Verified: provider passes each raw hook return straight into `*SessionContext.Provider value=`
  (lines 311–324). Memoizing the 6 hook returns restores isolation.

Secondary (verified):

- Returning signed-in users eagerly mount the ~1MB wallet SDK post-paint via a plain effect
  (`wallet-gate.tsx:70–78`). Guests correctly unaffected.
- Icon barrel not tree-shaken: 76 Hugeicons through `app/components/icons.tsx` → 42 files;
  `optimizePackageImports` in `next.config.mjs` lists only `framer-motion`.
- Heavy tables re-render every row (only 2 `React.memo` in the app); compounds with the cascade.
- No bundle analyzer in the toolchain.
- Timers are all visibility-gated + cleaned up — no leaks.

## TASK 2 — Localization

**Infra:** English is source of truth with no dictionary — the key _is_ the English string;
missing keys silently render English (`translate-core.ts:12`, `use-translation.ts:80`).

**Key parity (union = 1,179 keys, 13 locales):** ZH 5 missing, ES 8, FR/JA/PT 70, DE 75,
NL/ID/KO/RU 114, AR/HI/TR 119.

Defects:

1. **166 `t()` literals in code exist in no locale** — whole surfaces render English. Worst:
   entire Swap/Express surface (`swap-page-client.tsx`), transaction-progress narration in 11/13
   (`processing-narration.tsx:174`), dashboard portfolio labels + "Your position" hero tab +
   Net-Portfolio tooltip.
2. **~106 keys translated in ZH/ES only**, never propagated to the other 11.
3. **2 borrow-gate strings** are keys whose value equals English in all 13 (`fr.ts:394,:483`).

**Terminology:** symbols/brands correctly untranslated. "Multiply" inconsistent (literal in ES/FR
vs "leverage" in DE/RU/JA/ZH); "Cooldown" half-translated; ES accents ("Precaucion",
"Perdida impermanente").

**Root cause:** existing i18n tests are curated-list based and _tolerate_ the all-but-one-locale
case; no code-derived parity gate in CI.

**Overflow (LOW):** blocked-CTA labels run 1.5–2.3× English in DE/ES/RU/ID; need mobile-width check.

## TASK 3 — Pricing

**Verdict:** sandbox with a thin, inconsistent live-price veneer. Two parallel "current price"
systems read inconsistently.

- **F1 (HIGH):** live DefiLlama oracle vs hardcoded baseline `ETH:1934`, `BTC:65000`
  (`sandbox-baseline-prices.ts:30–39`). Split is deliberate (documented in file header) but nothing
  reconciles them; `convex/prices.ts` "real production price" comment is false on most surfaces.
- **F2 (HIGH):** same token shows live price in borrow list (`borrowable-assets-table.tsx:482`) and
  baseline price on its detail tile (`convex-detail.ts:435`).
- **F3 (HIGH, genuine defect):** borrow-list token quantities = baseline-USD ÷ live-oracle
  (`borrowable-assets-table.tsx:336,:346`) — reconciles to neither, off by ~35%+.
- **F4 (MED):** detail price chart disagrees with tile and is date-stale (ETH series ends
  $1,791.81 dated 2026-06-03, `token-price-series.ts:8–16`); mock vs convex tiles differ.
- **F6 (MED, clean bug):** oracle ingestion filters only `typeof price !== "number"`
  (`convex/prices.ts:163`) — NaN/0/negative pass; `confidence` stored but never used.
- **F5/F7/F8 (LOW, sandbox-acceptable):** LP price magic heuristic (`borrow-sim.ts:101`);
  prices keyed by symbol not chainId+address; `EURC:1.08` static.

**Positives (no action):** decimals are bigint fixed-point, central, never inferred from symbol
(`credit-engine/units.ts`); freshness/stale signalling real and tested
(`prices-freshness.test.ts`); FX canonical USD→fiat, 14 currencies.
